# Security

This app runs a small server on your own computer (`127.0.0.1` only) and stores your Spotify and Twitch
logins in `~/.rogue-radio-overlay/` (readable only by you). Nothing is sent anywhere except to Spotify,
Twitch and LRCLIB.

If you find a security problem, please report it privately through
[GitHub's private vulnerability reporting](https://github.com/ShawnGoff/RogueRadio/security/advisories/new)
instead of opening a public issue. This is a personal project, so there is no guaranteed response time,
but I'll look at reports as soon as I can.
